# Alex Morgan sample portfolio

Fictional profile and three concept projects demonstrating existing APL Studio components. Original artwork was created for this demo. No real clients or credentials are used.

With the builder running, open http://127.0.0.1:5173/demos/alex-morgan/.

This page uses the existing Preview component and validated project document. It adds no new public-site component or style. The contact form is sample-only. Project links point to example.com placeholders.

To edit it, use Import backup in APL Studio and choose alex-morgan.apl.json from this folder. This creates a separate project. The earlier partially assembled browser project is preserved.

Settings: Editorial palette and serif font, split hero, Gallery portfolio collection, three desktop columns, two tablet columns and one mobile column, Gentle lift motion, about text, contact form, shared header/footer.

Full-page view: http://127.0.0.1:5173/demos/alex-morgan/full.html. It uses the same Render/config as Preview, with local anchor navigation for this demo URL.
