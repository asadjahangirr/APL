# Dependencies and assets

The source uses Next.js, React, Tailwind CSS, Zod, and (when selected) Supabase JS. Verification uses Playwright. Their packages retain their own licenses; inspect installed package LICENSE files before redistribution.

No private builder package is required. Fonts use the visitor's system font stack; no remote font requests occur. Uploaded images are supplied by the project owner, who is responsible for their rights.

The APL-authored generated application source may be used, modified and deployed for personal or commercial websites. Third-party licenses and image ownership still apply.
